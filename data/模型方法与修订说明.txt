# ERS模型方法与代码修订说明

## 1. 正式模型口径

本提交包统一采用ERS模型1.2.0正式口径：

```text
ERS = ERM × WoI × CF
```

- `ERM`：用第二轮证据中五类风险源结构进行模糊推理；
- `WoI`：用专家和公众问卷进行 FAHP 相对重要性计算；
- `CF`：用有效证据数量和数据源覆盖对结果进行可信度修正；
- 只计算 4 个重点领域中的 5 类核心伦理风险，不将“破坏生态环境”列入最终 20 项结果。

本提交包不混用其他治理优先级公式。所有正式结果均由本目录中的代码、配置和标准输入生成。

## 2. ERM 如何计算

### 2.1 数据源内占比

对每个“领域—风险—数据源”，计算：

```text
风险源占比 = 该风险源出现记录数 / 该风险有效记录数
```

### 2.2 数据源加权聚合

基准数据源权重为：WOS 1.0、知网 0.9、谷歌 0.6、百度 0.5、微博 0.3。

先对各风险源的原始占比进行数据源加权平均，其中加权和除以实际参与聚合的数据源权重累加值；再在五类风险源之间统一归一化，使其和为 1。这个步骤得到的是“风险源构成”，不是风险发生率。

设 `p_ijks=n_ijks/N_ijs`，参与聚合且有有效记录的来源集合为 `S_ij`，则正式顺序为：

```text
a_ijk = Σ(s∈S_ij)(w_s × p_ijks) / Σ(s∈S_ij)w_s
p̄_ijk = a_ijk / Σ_k a_ijk
```

不得先将每个来源内部的五类占比标准化后再加权。由于一条证据可以同时命中多个风险源，各来源的五类原始占比之和可能不同，因此两种顺序通常不等价。

### 2.3 模糊化与推理

每个风险源结构占比被映射到 Low、Medium、High 三个模糊集合。输入隶属函数和输出隶属函数全部写在 `配置/模型配置.json` 中。

程序采用原模型的 Mamdani 式加权最大聚合：

```text
某等级激活度 = max(该风险源在该等级的隶属度 × 该风险源相对权重)
```

再用 min 截断三个输出模糊集合、max 合并，并用质心法解模糊，得到 0—100 的 ERM。

客观地说，这是一套“Mamdani 式聚合”，但不是由大量“如果—那么”专家规则组成的完整规则库。它的优势是可复算；局限是隶属函数边界仍带有方法设定，需要通过单因素扰动检验。

## 3. WoI 如何计算

### 3.1 直接比较与排序统一

- 个性化算法、机器视觉：读取直接两两比较题；
- 个性化算法的第二份公众问卷、自动驾驶、服务机器人：将完整排序转换为两两偏好；
- 偏好方向被映射为三角模糊数，基准强度为 3。

### 3.2 群体内聚合

先在专家组和公众组内分别对同一风险对做几何平均，形成各自的模糊比较矩阵，再用模糊几何平均法求权重。

### 3.3 组间合成

基准设定为专家组 : 公众组 = 5 : 1：

```text
组合权重 = (5 × 专家组权重 + 1 × 公众组权重) / 6
```

这是“组权重 5:1”，不是“每名专家答卷乘 5”。样本量只影响组内聚合，不会把 5:1 的含义改成 `5×专家样本数 : 公众样本数`。

自动驾驶和服务机器人原问卷按六项排序。程序先在六项中计算组内权重，再剔除生态风险，对五项核心风险重新归一化。`04_WoI_FAHP明细.csv` 同时列示剔除前值和再归一化分母。

### 3.4 一致性

程序对聚合后的中值比较矩阵计算一致性比率 CR。CR 是群体聚合矩阵的诊断，不等同于逐份答卷都通过一致性检验。

## 4. CF 如何计算

```text
E = Σ(该组合在各数据源中的有效证据记录数)
Q = E / (E + 90)
p_s = 该来源有效记录数 / E
H = -Σ(p_s × ln p_s)
C = exp(H) / 全部数据源数
CF = sqrt(Q × C)
```

数据来源权重只用于ERM中的风险源结构聚合，不进入CF。Q采用连续半饱和函数，证据增加时持续上升但边际贡献递减；C等于香农熵对应的有效来源数除以全部来源数，同时反映来源覆盖和分布均衡程度。`E`是加总后的有效证据记录数，不称为统计学意义上的“有效样本量”；C衡量来源多样性，不代表来源质量。

CF 只表示证据数量和来源覆盖对结果的支撑程度，不是统计置信区间，也不是风险概率。

## 5. ERS 与指数化

计算时使用未提前四舍五入的 ERM、WoI 和 CF：

```text
ERS_raw = ERM × WoI × CF
ERS_指数化 = ERS_raw / 全部20项中的最大ERS × 100
```

旧代码先把 ERM 四舍五入到两位再进入 ERS。本版只在导出时格式化，减少中间舍入误差。

## 6. 代码审计后修正的事项

| 旧代码问题 | 本版处理 | 对结果的影响 |
|---|---|---|
| 写死“第六次讨论”等外部路径，移动文件即失败 | 所有路径相对发布包，标准输入随包提供 | 解决跨电脑运行问题 |
| 风险源权重缺失时静默保留默认0.2 | 缺失状态、采用权重和处理说明全部写入CSV | 个别ERM会变化 |
| 自动驾驶、服务机器人整组使用0.2等权 | 将原专家问卷的风险成因排序转为成对偏好并进行FAHP聚合 | 两个领域的ERM和部分排名发生实质变化 |
| 专家权重5、公众权重1按每份答卷施加 | 先组内聚合，再按组权重5:1合成 | 部分WoI和排名会变化 |
| 个性化算法第二份公众排序问卷未进入WoI | 纳入公众组并统一转成两两判断 | 个性化算法WoI更完整 |
| 直接问卷重复风险对可能被重复计权 | 先在同一受访者同一风险对内合并 | 避免重复列双倍权重 |
| ERM先保留两位再进入ERS | 全精度计算，导出时再显示小数 | 消除小幅舍入误差 |
| 数据来源权重同时进入ERM与CF | 来源权重仅用于ERM；CF不再使用来源质量权重 | 避免来源质量被重复计权，需重算ERS与全部稳健性结果 |
| CF硬阈值与简单覆盖率导致19项取1 | Q改用连续半饱和函数，C改用有效来源多样性 | 恢复CF区分度并保留边际递减性质 |
| 1200情景混在主要结果中 | 单因素扰动作为主检验；1200情景独立到后台附件 | 汇报更直接 |
| 缺少完整输入和结果校验 | 加入组合完整性、权重和、数值区间、排名和情景数检查 | 错误会直接暴露 |

## 7. 当前基准结论

正式结论以本次自动输出为准。基准情景下，前五项依次为：机器视觉—侵犯隐私、自动驾驶—决策不自主受控、自动驾驶—权责归属不清或失当、服务机器人—决策不自主受控、个性化算法—侵犯隐私。

其中，自动驾驶和服务机器人的部分风险成因题只覆盖部分风险源。排序转FAHP后，权重可能集中在已覆盖的风险源，因此相关ERM应解释为“当前问卷题项与证据结构共同形成的结构性信号”，不能解释为现实风险概率陡增。

联合情景中的覆盖比例仅表示在预设参数集合中进入前5名的情景频率，不是统计概率。稳健性分层使用基准排名、Top5覆盖率和中位排名进行透明判定，并由代码自动输出。

## 8. 正式结果口径

当前发布包中的代码、配置和标准输入共同定义唯一正式复算口径。历史讨论版本不再进入发布包输出，也不生成新旧结果对照；需要解释方法修订时，以本文件第6节记录的规则变化为准。

## 9. 仍然存在的模型边界

1. 当前没有企业级事故、暴露量、控制缺口和损失数据，ERS 只能形成领域层关注顺序。
2. ERM建立在风险源相对构成上；证据总量主要通过CF体现，因此它不是发生频率。
3. 模糊隶属函数边界和FAHP偏好强度仍是方法设定，不能包装成客观真值。
4. 自动驾驶和服务机器人已使用原问卷成因排序，不再整组等权；但排序题与前两个领域“发生×影响”直接判断的采集口径不同，且部分风险只覆盖少数风险源，仍应通过新问卷统一口径。
5. 1200情景只是压力测试设计，不是1200个现实世界样本。
